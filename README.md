# Ak-ll-At-k-Ayr-t-rma-ve-Geri-D-n-m-Analizi
PYTHON PROGRAMLAMA PROJESİ| Bu proje, atıkların türlerine göre sınıflandırılmasını ve geri dönüşüm verilerinin analiz edilmesini amaçlamaktadır. Python kullanılarak geliştirilen proje ile geri dönüşüm bilincinin artırılması ve çevre dostu çözümler üretilmesi hedeflenmektedir.
Amaçlarımız
- Atıkları türlerine göre sınıflandırmak.
- Geri dönüşüm verilerini analiz etmek.
- Çevre bilincini desteklemek.
